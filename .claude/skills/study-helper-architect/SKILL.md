# Study Helper Architect

Use esta skill quando precisar tomar decisões de arquitetura do Study Helper.

Contexto:
Study Helper é uma plataforma web interativa para estudo do mercado financeiro usando metáfora de cidade/ecossistema financeiro.

Prioridades:
- Next.js + TypeScript
- Tailwind + shadcn/ui
- Cidade 2D/2.5D antes de 3D
- Dados mockados antes de API real
- Componentes pequenos
- Baixo custo inicial
- Facilidade para agente trabalhar

Regras:
- Não alterar código nesta skill sem pedir confirmação.
- Gerar plano curto.
- Dividir em sprints pequenas.
- Explicar riscos.
