# Study Helper Data Modeler

Use esta skill para modelar dados financeiros e entidades do Study Helper.

Entidades principais:
- Asset
- PriceSnapshot
- VisualNode
- Lesson
- User
- Favorite

Regras:
- Começar simples.
- Separar moedas, ações, índices e cripto por tipo.
- Não criar schema complexo demais no início.
- Pensar em Prisma/PostgreSQL.
- Criar seeds claros para desenvolvimento.
