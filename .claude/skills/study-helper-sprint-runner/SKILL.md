# Study Helper Sprint Runner

Use esta skill para executar uma sprint pequena do Study Helper.

Regras obrigatórias:
- Antes de alterar, listar plano curto.
- Não refatorar tudo.
- Não adicionar dependência sem justificar.
- Não rodar build/typecheck pesado se o usuário disser que a máquina está fraca.
- Trabalhar em poucos arquivos.
- Manter mocks funcionando.
- Ao final, listar arquivos alterados, comandos executados e como testar.

Formato de saída:
1. Plano
2. Execução
3. Validação
4. Arquivos alterados
5. Próxima etapa
