# Study Helper UI Reviewer

Use esta skill para revisar telas, layout, UX e coerência visual do Study Helper.

Checklist:
- A tela comunica cidade financeira?
- Moedas e ações estão visualmente separadas?
- Alta/queda/neutro têm cores claras?
- O painel do ativo é legível?
- O usuário entende o que clicar?
- A interface roda bem em máquina fraca?
- Há excesso de efeitos pesados?
- O visual serve para portfólio?

Saída:
- Nota de 1 a 10
- Problemas encontrados
- Melhorias prioritárias
- Próxima tarefa recomendada
