# 02 — Contexto do Criador

## Perfil operacional

O criador do projeto, Sipcelo, e programador, estudante e criador de conteudo. Ele usa IA como parceira de raciocinio, criacao e execucao.

Esta cursando o **Bootcamp AI Java Backend**, o que define a escolha de Java Spring Boot como stack principal de backend para o Study Helper.

Areas recorrentes de trabalho:

- programacao (foco atual: Java Spring Boot, TypeScript);
- automacao;
- marketing;
- funis;
- afiliados;
- criacao de conteudo;
- projetos de renda;
- ferramentas com IA.

## Contexto atual de aprendizado

O Bootcamp AI Java Backend e o eixo de aprendizado tecnico atual. O Study Helper deve **refletir esse aprendizado**, usando Java Spring Boot nos servicos de backend novos em vez de Node.js/NestJS.

O primeiro servico Java planejado e a **API Interact** — um servico de Speech to Text educacional que demonstra aplicacao pratica do bootcamp.

## Como este projeto deve respeitar esse perfil

O Study Helper deve ser um projeto com:

- impacto visual e educacional;
- potencial de portfolio demonstravel;
- possibilidade de desenvolvimento em sprints pequenas;
- documentacao forte para uso com agente;
- stack moderna e empregavel (TypeScript no front, Java no backend);
- baixo custo inicial;
- capacidade de virar produto, conteudo e case tecnico.

## Estilo de execucao esperado

1. Etapas pequenas com checkpoint.
2. Decisao por uso real, risco e custo.
3. Prototipo antes de complexidade.
4. Visual forte com arquitetura limpa.
5. Agente de IA como executor controlado.
6. Humano mantendo direcao do produto.

## O que evitar

- projeto grande demais sem MVP definido;
- 3D complexo antes de dados e UX solidos;
- dependencia de API paga no inicio;
- arquitetura overengineered;
- agente alterando direcao sem aprovacao;
- features que nao ajudam portfolio, aprendizado ou produto.
- confundir modulo financeiro com o produto inteiro.
