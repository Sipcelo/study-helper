# 36 — Direcao da Plataforma de Estudos

## O que e o Study Helper

Study Helper e uma plataforma web interativa de estudos para **programacao, carreira e aprendizado guiado em tecnologia**.

Nao e uma plataforma financeira. O modulo financeiro e a primeira vertical construida para validar o conceito visual e gerar portfolio, mas o produto central e voltado para tecnologia e carreira.

---

## Por que comecar com financas?

O modulo financeiro foi escolhido como ponto de partida por tres razoes:

1. **Conceito visual forte**: cidade financeira e uma metafora clara e demonstravel;
2. **Dados bem estruturados**: ativos, precos e indicadores sao faceis de mockar e evoluir;
3. **Portfolio atrativo**: visualizacoes financeiras sao valorizadas em processos seletivos.

O modulo financeiro cumpre seu papel ao estabelecer o padrao visual, tecnico e de documentacao da plataforma.

---

## Qual e o publico principal

| Perfil | O que busca |
|--------|-------------|
| Estudante de programacao | Trilha clara, conceitos visuais, recursos curados |
| Junior em inicio de carreira | Orientacao pratica, checklist de portfolio, roadmap |
| Pessoa em transicao para tech | Ponto de partida, linguagem acessivel, progresso visivel |
| Iniciante em financas | Visualizacao simples, contexto educacional, sem jargao |

O foco principal e **programacao e carreira**. Financas e um modulo complementar.

## Proximo grande modulo: Programacao

O modulo de programacao sera a segunda vertical da plataforma.

Objetivo: criar um mapa visual de trilhas de aprendizado para programacao.

O que deve incluir:

- mapa visual de linguagens, frameworks e conceitos;
- trilha de Java (alinhada ao Bootcamp AI Java Backend);
- trilha de TypeScript/Next.js;
- painel de conceito com explicacao didatica;
- recursos curados por topico;
- progresso pessoal (futuro).

---

## Java Spring Boot como backend estrategico

O backend principal para novos servicos sera **Java Spring Boot**, alinhado ao Bootcamp AI Java Backend em andamento.

Razoes:

- aprendizado real aplicado ao produto;
- empregabilidade no mercado brasileiro;
- stack enterprise demonstravel em portfolio;
- primeiro servico: **API Interact** (Speech to Text educacional).

Node.js/NestJS segue como auxiliar para o que ja existe, sendo substituido gradualmente.

---

## API Interact — Primeiro servico Java

A **API Interact** sera o primeiro servico Spring Boot do Study Helper.

Objetivo: ouvir, pensar e agir — transformar audio em acao educacional estruturada.

Pipeline:

1. **Ouvir** — receber audio do usuario
2. **Transcrever** — converter fala em texto (Speech to Text)
3. **Classificar** — identificar intencao educacional
4. **Agir** — retornar resposta ou acao estruturada

Intencoes planejadas:

| Intencao | Descricao |
|----------|-----------|
| `EXPLAIN_CONCEPT` | Explicar um conceito tecnico ou financeiro |
| `GENERATE_STUDY_PLAN` | Criar plano de estudos personalizado |
| `SIMULATE_INTERVIEW` | Simular pergunta de entrevista tecnica |
| `REVIEW_ANSWER` | Avaliar resposta do usuario |
| `OPEN_RESOURCE` | Abrir recurso ou trilha especifica |
| `COMPARE_CONCEPTS` | Comparar dois conceitos (ex: REST vs GraphQL) |

Dominios de atuacao: programacao, carreira, estudos e financas.

Ver detalhes em: `docs/38_API_INTERACT_SPEECH_TO_TEXT.md`

## O que NAO e o Study Helper

- Nao e uma plataforma de trading ou analise financeira profissional.
- Nao e um robo de investimentos.
- Nao e um substituto de corretora ou aplicativo bancario.
- Nao e apenas um projeto tecnico sem publico real.

---

## Direcao editorial dos modulos

Cada modulo deve seguir os mesmos principios:

1. **Visual antes de texto**: metafora visual clara como entrada;
2. **Explicacao simples**: linguagem acessivel para iniciantes;
3. **Trilha clara**: o usuario sempre sabe o proximo passo;
4. **Contexto real**: conectar conceito com aplicacao pratica;
5. **Portfolio value**: cada modulo deve ser demonstravel em entrevistas.
